# AI-Assisted Development Workflow Comparison

## 1. Objective

The purpose of this assignment was to compare two different AI-assisted development workflows by implementing the same Settings Form feature for my Student Productivity application. I used Codex in VS Code for both experiments.

## 2. Round 1 – Vague Prompt

In Round 1, I provided Codex with a single, simple prompt:

"Build a settings form for my Student Productivity application."

I did not provide detailed requirements, validation rules, accessibility instructions, or testing instructions. I reviewed the generated code and tested the feature manually.

The implementation was completed with limited guidance. During my review, I checked the form fields, save functionality, and validation behavior.

## 3. Round 2 – Detailed Prompt

In Round 2, I used a fresh Codex session and provided detailed instructions. First, I asked Codex to inspect the project and create an implementation plan.

I specified requirements for display name, email validation, notification preferences, accessible labels, error messages, and successful form submission.

I also instructed Codex to write automated tests, run them, and fix any failures.

This approach provided better control over the implementation process and made verification an important part of development.
