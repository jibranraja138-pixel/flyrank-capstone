# AI Development Rules

## 1. Form Accessibility

Every form input must have a properly associated label. Forms must support keyboard navigation and provide clear validation messages.

## 2. Form Validation

All required form fields must be validated before submission. Invalid data must never display a success message.

## 3. Automated Testing

Every new form feature must include appropriate tests. Run the relevant tests after implementing or modifying functionality.

## 4. Existing Project Structure

Follow the existing project structure, coding conventions, and installed dependencies. Do not introduce unnecessary libraries.

## 5. Code Verification

After implementing a feature, review the modified files, check for errors, and report the actual test results.
