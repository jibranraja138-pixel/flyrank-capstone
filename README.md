# FlyRank AI Capstone

## Overview

This repository is the starting point for my FlyRank AI capstone project. It establishes the development environment, repository structure, and version-control conventions for the project.

## Project Status

**Current phase:** Setup

The initial setup includes:

* Development environment verification
* Git and GitHub configuration
* Repository documentation
* AI-assisted development workflow

## Technology Stack

* **Runtime:** Node.js LTS
* **Version control:** Git
* **Editor:** Visual Studio Code
* **AI coding assistant:** OpenAI Codex

Additional frameworks, libraries, and application technologies will be documented once the capstone requirements determine the final stack.

## Getting Started

### Prerequisites

* Node.js LTS
* npm
* Git
* Visual Studio Code

### Verify your installation

Run these commands in your terminal:

```bash
node --version
npm --version
git --version
```

## Development Workflow

1. Make focused changes.
2. Review AI-generated changes before accepting them.
3. Run relevant checks after making changes.
4. Use Conventional Commits for all Git commits.
5. Keep project documentation up to date.
