# AI Coding Instructions

## Project Context

This repository is the starting point for my FlyRank AI capstone project.

The current phase is setup. Do not assume application features or frameworks that have not been specified by the project requirements.

## Technology Stack

* Runtime: Node.js LTS
* Package manager: npm
* Editor: Visual Studio Code
* Version control: Git
* AI coding assistant: OpenAI Codex

Additional frameworks, libraries, databases, and testing tools must be documented when they are selected.

## Coding Conventions

* Prefer clear, readable, maintainable code.
* Use descriptive names for files, variables, functions, and components.
* Keep changes focused and avoid unnecessary dependencies.
* Follow the conventions of the selected language and framework.
* Handle errors explicitly when implementing executable functionality.
* Avoid duplicating existing functionality.

## AI-Assisted Development Workflow

* Inspect the relevant files before making changes.
* Explain the proposed approach for substantial changes.
* Make small, reviewable edits.
* Do not overwrite unrelated user changes.
* Do not run destructive commands without explicit approval.
* Never expose API keys, passwords, access tokens, or other secrets.
* Review the diff after making changes.
* Run applicable tests or validation commands and report their actual results.
* Do not claim that tests passed unless they were executed successfully.

## Git Conventions

Use Conventional Commits for every commit.

Examples:

* `docs: add project README`
* `chore: add repository configuration`
* `docs: define AI coding conventions`
* `docs: improve README setup instructions`

Use lowercase descriptions, keep them concise, and describe the actual changes.

## Documentation

* Keep README.md accurate and up to date.
* Document setup prerequisites and commands.
* Do not invent project features or claim unverified functionality.
